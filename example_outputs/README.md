# Example output

[`example_screening_export.csv`](example_screening_export.csv) is a **real file produced by this tool** using the built-in search. It's here so you can see exactly what you'll get before running anything yourself.

Open it in Excel, Numbers, or Google Sheets. Each row is one article, with its title, abstract, authors, journal, year, DOI, and link already filled in. The last three columns (**Screening Decision**, **Exclusion Reason**, and **Screening Notes**) are left blank for you to complete during screening.

When you run the tool, your own file lands in the project's main folder (not here), named with the date and time of the run.
